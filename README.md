# DrivingSimulator - 沉浸式街景虚拟驾驶系统

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.100%2B-009688.svg)](https://fastapi.tiangolo.com/)

[![Leaflet](https://img.shields.io/badge/Leaflet-1.9.4-199900.svg)](https://leafletjs.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**DrivingSimulator** 是一款基于真实全球街景的沉浸式虚拟自驾模拟系统。系统集成了高精度路径规划、Google 全景街景抓取与切片合成、Three.js 360° 球体全景渲染、拟真驾驶物理模型与仪表盘 HUD。用户只需在地图上选定起终点，即可在全球各大城市的真实道路中自由驾驶或巡航漫游。

---

## 🌟 核心特性

### 1. 交互式地图路线规划
- **多图层底图与街景网覆盖**：支持 Google HD 实拍卫星混合图、纯卫星图、标准道路图以及实时蓝色街景覆盖网（SV Coverage），直观查看全球街景覆盖区域。
- **开源 OSRM 智能导航**：基于开源 OSRM 路由服务规划真实行车路线；支持行驶方位角朝向约束，有效避免路口误判与绕路掉头。
- **智能逆地理编码**：整合 OpenStreetMap Nominatim 服务，自动解析起终点的国家、城市及路名。

### 2. 高效异步全景下载与智能管线
- **高并发断点续传**：基于 `streetlevel` 与 `aiohttp` 异步并发检索与下载 360° 瓦片并合成全景图；支持随时一键暂停/取消任务。
- **车道朝向一致性校验**：根据规划路线前进矢量过滤逆向拍摄点，保证行驶视角始终正对前方。
- **全局资产复用与缓存**：以 `pano_id` 为基准去重和持久化缓存，重叠路线无需重复下载。
- **无缝路线追加（Route Extension）**：到达终点后，可一键向前继续选点扩展线路，实现无限延伸的长途自驾。

### 3. 沉浸式 3D 虚拟座舱 (Three.js)
- **360° 全景球体视差渲染**：支持鼠标任意角度环顾观察街景，滚轮无级缩放广角与长焦视野（FOV 30°~100°）。
- **拟真驾驶动力学**：支持手动油门加速、线性刹车、惯性阻尼滑行、定速巡航（Cruise Control）与瞬时车速锁定（Speed Lock）。
- **航向实时微调**：内置车头朝向纠偏算法，支持快捷键实时微调车头中心对准当前车道。
- **现代化驾驶舱 HUD 仪表盘**：
  - 实时车速表（km/h）与驾驶模式指示（加速/制动/巡航/锁速）。
  - 里程统计（当前已行驶里程 / 全程总里程）。
  - 街景拍摄时间水印（年份/月份）。
  - 车辆画中画迷你地图（Mini-Map），实时同步当前 GPS 坐标与车头朝向指针。

### 4. 路线地址簿持久化 (SQLite)
- 路线及规划参数自动/手动保存至 SQLite 数据库（`routes.db`）。
- 支持一键调取历史路线、重新自驾或快速管理路线。

## 🛠️ 技术架构

- **后端核心**：`FastAPI` + `Uvicorn` + `Asyncio` + `aiohttp` + `SQLite3`
- **全景数据解析与处理**：`streetlevel` + `Pillow`
- **前端视效与交互**：`Three.js (r128)` + `Leaflet.js` + 原生 HTML5 / CSS3（玻璃拟态暗黑风格）
- **数据源服务**：Google Street View / Tiles、OSRM Routing Engine、OpenStreetMap Nominatim

```text
DrivingSimulator/

├── .env                        # 系统环境变量配置文件 (端口、网络代理、数据路径等)
├── routes.db                   # 路线地址簿 SQLite 数据库 (首次运行自动生成)
└── streetview_route/           # 街景数据与瓦片缓存目录 (运行时生成)

    ├── tile_cache/             # 地图瓦片本地缓存 (*.png)
    └── route_manifest.json     # 当前正在驾驶路线的元数据清单
```

## 🚀 快速上手

### 运行环境要求
- Python 3.9 或更高版本
- Windows / macOS / Linux
- 网络环境：由于 Google 街景和地图瓦片服务需要海外网络访问，若在受限网络环境下，需在 `.env` 中配置 HTTP/SOCKS 代理。

### 方式一：Windows 一键启动（推荐）
直接双击项目根目录下的 **`start.bat`**：
1. 脚本将自动检测端口冲突并释放；
2. 自动检查并安装缺失的 Python 依赖包；
3. 启动 Web 服务并在 2 秒后自动唤起默认浏览器访问。

### 方式二：手动启动

1. **安装依赖**
   ```bash
   pip install streetlevel aiohttp pillow fastapi uvicorn python-dotenv
   ```

2. **配置环境变量**
   在项目根目录下查看或编辑 `.env` 文件：
   ```ini
   HOST=0.0.0.0
   PORT=3000
   
   # 网络代理设置 (如走本地梯子客户端: http://127.0.0.1:7890 或局域网代理)
   # 若环境支持直连，请直接留空 (PROXY_URL=)
   PROXY_URL=http://127.0.0.1:7890
   
   # 街景与数据缓存目录
   DATA_DIR=streetview_route
   
   # SQLite 路线数据库路径
   DB_PATH=routes.db
   ```

3. **运行服务**
   ```bash
   python server.py
   ```
   启动后，使用现代浏览器访问：`http://127.0.0.1:3000`

## 🎮 操作指南

### 1. 路线规划与街景准备
1. 进入主界面顶部的 **【路线规划】** 视图。
2. 在地图上右侧或直接左键点击选择**起点 (A)** 与 **终点 (B)**。
   - 地图右上角图层控件可切换查看**蓝色街景覆盖路网**，建议将起终点放置在覆盖蓝色线条的道路上。
3. 点击 **【规划路线】** 查看路线长度、预计全景图张数与道路轮廓。
4. 点击 **【下载全景街景】**，系统将在后台并发抓取全景帧并合成图像；下载完成后点击 **【立即开始虚拟驾驶】** 自动切入座舱。

### 2. 虚拟驾驶控制键位

| 按键 / 操作 | 功能描述 |
| :--- | :--- |
| <kbd>W</kbd> 或 <kbd>↑</kbd> | **踩油门加速**（持续按住平滑加速） |
| <kbd>S</kbd> 或 <kbd>↓</kbd> | **踩刹车减速 / 倒车** |
| <kbd>Space</kbd> 空格键 | **启停定速巡航**（自动维持当前巡航车速） |
| <kbd>U</kbd> 键 | **锁定 / 解锁车速**（锁定当前瞬时速度，松开油门不掉速） |
| <kbd>[</kbd> / <kbd>]</kbd> 键 | **车头航向纠偏**（每次向左 / 向右微调 5 度，使视角正对道路中线） |
| <kbd>P</kbd> 键 | **复位航向纠偏**（恢复原始计算航向） |
| <kbd>R</kbd> 键 | **视角归中复位**（观察视角重置为车头正前方） |
| <kbd>B</kbd> 键 | **重新发车**（车辆瞬移回路线起点重新驾驶） |
| **鼠标左键拖拽** | **360° 自由环顾**车窗外全景街景 |
| **鼠标滚轮** | **视场角缩放 (FOV)**（广角全景 / 局部特写放大） |

## ⚙️ 进阶参数调优

如需根据设备性能或网络状况调整抓取策略，可直接在规划参数或 `server.py` 中调整：
- **采样步长 (`step_meters`)**：默认为 20 米。若追求更加顺滑的逐帧画面，可调小至 8~10 米；若追求下载速度，可调大至 25~30 米。
- **画质等级 (`zoom_level`)**：默认为 3（对应全景分辨率 4096×2048），兼顾画质与下载速度；最高可设为 4 或 5（超高画质，切片数量随指数增长）。
- **并发控制 (`Semaphore`)**：默认并发限制为 5~6 个协程，防止高频触发上游服务频率限制。
